Comment ça marche

1. Dites ce que vous pouvez donner…

Un objet, un repas, un coup de main en bricolage, du soutien scolaire, une visite, une écoute, une prière… Publiez librement tout ce que vous souhaitez donner, avec jusqu'à six photos. Plus il y a de dons, plus chacun trouve ce qu'il lui faut. Vous pouvez modifier votre annonce et ajouter des photos à tout moment.

{{ verset('deux_tuniques') }}

2. …et ce que vous aimeriez recevoir

C'est le plus important : chacun est invité à dire aussi ce dont il a besoin. Recevoir, c'est permettre à l'autre de donner. Si votre besoin est de première nécessité (se nourrir, se loger, se vêtir, se soigner, ne plus être seul), indiquez-le : il sera présenté en priorité.

{{ verset('demandez') }}

3. Le donateur choisit

Pour chacun de vos dons, le site vous propose une liste de receveurs potentiels, avec la raison de chaque suggestion. Les besoins de première nécessité sont toujours en tête de liste. Vous voyez le profil et les avis de chaque personne, et c'est vous seul qui décidez.

Les membres peuvent aussi vous signaler qu'un de vos dons leur serait utile : ils apparaissent alors dans votre liste. Le site vous prévient par une notification (et par e-mail si vous le souhaitez) dès qu'un besoin correspond à l'un de vos dons.

{{ verset('donne_a_qui_demande') }}

4. Dans le secret

Votre identité de donateur n'est jamais affichée. Quand vous donnez, vous choisissez ce que vous partagez avec le receveur (un prénom, un moyen de contact, un lieu de rendez-vous…). Dans les messages du don, vous apparaissez comme « le donateur ». On peut y joindre des photos, visibles seulement par les personnes concernées.

{{ verset('main_gauche') }}

5. Les dons voyagent avec vous

Indiquez vos déplacements prévus dans Mes trajets. Quand un don doit aller de la ville du donateur à celle du receveur, le site propose les membres qui font ce trajet, pour éviter des frais d'expédition inutiles.

{{ verset('samaritain') }}

6. Prier les uns pour les autres

Sur chaque besoin, un bouton « Je prie pour vous » permet de porter cette intention dans la prière. La personne en est prévenue : elle sait qu'elle n'est pas seule.

{{ verset('deux_ou_trois') }}

7. Après le don : rendre grâce

Le receveur peut écrire un mot d'action de grâce, avec une photo s'il le souhaite. Il est transmis au donateur et peut être publié, sans aucun nom, sur la page « Actions de grâce ».

{{ verset('lepreux') }}

8. Un avis fraternel, et le pardon

Le donateur peut laisser un avis bienveillant et objectif ; le receveur peut y répondre. Ces avis aident les donateurs suivants à donner en connaissance de cause, sans jamais empêcher un don. En cas de difficulté, on en parle d'abord seul à seul, dans les messages. Et le donateur peut retirer son avis à tout moment.

{{ verset('reprendre_son_frere') }}

Une mise en relation transparente

Cette première version du système de mise en relation est volontairement simple et explicable : elle compare les catégories, les mots utilisés et les villes, et place toujours en premier les besoins de première nécessité. Son code est ouvert ; chacun peut l'améliorer.
